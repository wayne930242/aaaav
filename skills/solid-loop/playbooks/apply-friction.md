# Apply friction notes

**You own one action per note.** Notes arrive classified as `misdirection` or `gap` by the Reflexive pass.

1. A note with no before/after contrast (the failed attempt and what revealed the cause) gets no placement; record it as unsupported.
2. Correct each misdirection: open the line named in `Led by` and rewrite it to state what `Found` established, or delete it when it has no correct form.
3. Place each gap: search the agent system for a statement of the `Found` fact. When one exists, the run could not reach it: sharpen the pointer or description that should have led there. When none exists, write it as one direct sentence where **Placement** puts it. A fact the change itself resolved, or a tool slip no project or skill owns, needs no placement.
4. Choose the **Mechanism** before writing prose, then **Hold the Size**.

**Reply:** one pair per note:

```text
Friction: <Found> (misdirection | gap)
Action: <corrected line | sharpened pointer | placed at <location> | enforced by <check> | resolved by the change | unsupported>
```
