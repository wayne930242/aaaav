# Compare

**You own the recommendation.** A recommendation is a judgment, not an agreement.

1. Fix the criteria that decide the choice before scoring any option.
2. **Observe, don't ask** for any criterion a check can settle.
3. Score each option against the criteria with evidence; say plainly when the premise or every option is wrong.

**Reply:** the recommendation and its deciding reason, then the options-by-criteria table and what would change the pick.
